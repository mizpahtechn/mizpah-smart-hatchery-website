Read before use

Dashboard guide

What this source-code implementation currently does.

Important: This is a front-end demonstration, not a secured production admin system. It contains sample records and does not connect to Supabase, a customer app, payments or a live inventory database.

Available in this prototype

  • Add and edit sample product records.
  • Edit prices and stock quantities in one shared in-browser dataset.
  • Publish/unpublish products individually or in bulk.
  • Search and filter products, prices, stock and orders.
  • Change sample order statuses.
  • Persist demo edits in this browser using local storage.
  • Responsive layout for desktop, tablet and mobile.

Required before real use

  • Staff sign-in and role-based authorization.
  • Server-side validation and secure database rules.
  • Shared product, price and stock data source for customer-facing pages.
  • Real order integration, audit history and deployment testing.

Never put service-role keys, passwords or payment secrets in this HTML file.
