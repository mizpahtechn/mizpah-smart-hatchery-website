Dashboard guide

What this source-code implementation currently does.

Production connection: This dashboard authenticates authorised staff through Supabase and reads and updates the live Mizpah product catalogue and customer order records. Actual access and write permissions are also governed by Supabase database policies.

Current connected features

  • Staff sign-in and active staff-account verification.
  • Live product catalogue management, including prices, stock and publication status.
  • Individual and bulk product publishing controls.
  • Live customer order retrieval and status updates.
  • Quotation and internal staff-note updates for customer orders.
  • Responsive layout for desktop, tablet and mobile.

Operational checks still required

  • Verify Supabase row-level security policies for each staff role.
  • Test product creation, editing, cancellation and deletion against the live database.
  • Verify customer catalogue synchronisation and order notification delivery.
  • Complete end-to-end testing on desktop and mobile before declaring production readiness.

Never put service-role keys, passwords or payment secrets in this HTML file.
