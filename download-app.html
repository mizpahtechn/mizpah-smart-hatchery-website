Mizpah Customer Referral

Share Mizpah. Grow Together.

Our Android app provides each eligible customer with a personal Mizpah referral code. Share that code with a new customer. They can enter it when placing an order on this website, or open a referral link that carries the code into the order form. Website and app referrals use the same customer referral programme.

Place an Order with a Referral Code →Get the Mizpah App

Referral attribution is recorded against the customer and rewards are processed only after a qualifying order has been confirmed as paid under the current programme rules.

1Open the app
Sign in to your existing Mizpah customer account.
2Copy your personal code
Open the referral feature and share your unique code with a new customer.
3Place an order on the website
The new customer enters the code in the referral field on the order form. Referral links can also use ?ref=YOURCODE.
Installation guide

How to Install the Android App

When the official APK is published, follow these steps to install it safely on your Android device.

1

Download the APK

Tap the official Download for Android button once the download link is activated.

2

Allow the installation

If Android asks, allow your browser or file manager to install apps from this source. Only proceed with the official Mizpah APK.

3

Install and open

Open the downloaded APK, tap Install, then launch Mizpah Smart Hatchery and sign in or create an account as required.

Security reminder: Download the application only from the official Mizpah website or another official distribution link announced by Mizpah. Android may display a security prompt for apps installed outside Google Play.
